What can I do on the Dynalogic Hyperion?

Click the amber CRT display to type directly, press the physical F1–F10 soft keys below the screen, or click any Try it button below to run a command or switch disks automatically:

B:MP Launch Microsoft Multiplan 1.06 for the Hyperion from Drive B:, with dynamic soft-key labels on Line 25.
DISKNAME Inspect the Hyperion diskette volume names mounted in Drive A: and Drive B:.
DIR A: List all system utilities and programs on the Master User Diskette in Drive A:.
CHKDSK C: Check the 90 KB Electronic RAM Disk (C:) automatically created in the upper 96 KB of the 256 KB RAM.
Diagnostics • F6 Boot the Hyperion Master Diagnostic Diskette and run TEST #3: Dynalogic CRT Attributes (underline, reverse, blink, superscript/subscript, bold, double-width).
Diagnostics • F3 Boot Diagnostics and run the 320×250 4-Shade Amber Low-Res Graphics test (CRT.BAS mode 85h).
Keyboard, Soft Keys, Paste & Disk Drag-and-Drop Reference
F1 – F10 Maps to the 10 Hyperion soft keys aligned under Line 25 (click the on-screen buttons or press F1–F10 on your keyboard).
Ctrl+V / ⌘V Paste text from your host clipboard directly into the Hyperion keyboard buffer.
Drag & Drop Drop any ImageDisk (.IMD) or raw sector (.IMG / .DSK) file onto the CRT screen to mount and boot it in Drive A:.
